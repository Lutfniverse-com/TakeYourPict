2. Pilih tema frame

Frame buatanmu

3. Atur stiker emoji

Seret emoji langsung di pratinjau untuk memindahkannya. Ketuk emoji untuk memilihnya, lalu atur ukuran dan putarannya di sini. Di komputer, scroll mouse di atas emoji untuk membesarkan atau mengecilkannya.

4. Buat atau ubah frame sendiri

Mau frame dengan karakter favoritmu? Buat PNG transparan berukuran 600×1500 px di aplikasi desain, lalu pasang lewat tombol di atas. Lubang transparan di posisi foto akan menampilkan fotomu.

Jika tombol unduh tidak bekerja, tekan lama gambar lalu pilih simpan.
